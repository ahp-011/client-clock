# Brand

- `logo.svg` — the full app mark: white rounded tile, black open **C**, blue
  square (`#1B4DFF`) seated in the notch.
- `mark.svg` — the same mark with no tile behind it.

The collapsed tab in the widget draws this mark live (as inline SVG) so it can
animate — the C turns and the square lifts on hover.

## Replacing it

Drop a square `logo.png` in this folder and it takes over the collapsed tab
(96×96 or larger). Delete it to go back to the built-in mark.
